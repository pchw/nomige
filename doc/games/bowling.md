# ボウリング（bowling）

## 概要

**一言ルール：1人1投。倒したピンが一番少ない人が負け。**

上から見たレーンで1投だけ投げる。ピンが連鎖して倒れていくのを全員で見守る。
グラスすべらせと同じく「決めて押すだけ」の操作で、結果が本数ではっきり出る。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 3〜10人 |
| 時間 | 1〜2分（1投2〜3秒の演出＋狙う時間） |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま操作する） |
| 各自スマホ | ○ |
| 隠し情報 | なし（投げのぶれの乱数だけ） |

## ルール

1. 開始プレイヤーはランダム。そこから席順に **1人1投ずつ**。ピンは毎回10本並べ直す。
2. 「位置」「方向」「強さ」を決めて「投げる」。
3. 全員が投げたら、倒した本数が一番少ない人の負け。
4. **同点のときは延長戦**：最下位で並んだ人だけでもう1投ずつ投げ、その中で一番少ない人の負け。また並んだら並んだ人でもう1投。延長戦を3回やっても決まらなければルーレット。

- 負けを決めるのは最下位の人たちだけなので、上位で並んでも（ストライク同士など）延長戦にはならない。

### 強さとぶれ

グラスすべらせの「強すぎると落ちる」にあたる危険として、**強く投げるほどピンは派手に飛ぶが、方向がぶれやすい**。

| 設定 | 強さ0のぶれ | 強さ100のぶれ |
| --- | --- | --- |
| 小さい（腕前勝負） | ±0.3° | ±2.5° |
| ふつう | ±0.6° | ±4° |
| 大きい（運まかせ） | ±1° | ±6° |

- レーンの両側は溝（ガター）。ボールの中心がピンに届く前にレーンの外に出たら、溝に沿って転がり0本。
### 倒れたピンの判定

上から見た画面ではピンが倒れる様子を描けないので、**当たって動いたピンは倒れた** と見なす（実際のボウリングでも、当たったピンはほぼ倒れる）。

- ボールやほかのピンに当たって、元の位置から 3 より動いたピンは倒れた扱い。レーンの中に残っていても1本。
- 溝や奥の穴に出たピンも倒れた扱い。
- 一度倒れた扱いになったピンは、その後どこで止まっても倒れたまま。
- 画面では、倒れた瞬間にピンを動いた向きへ横倒しの形に変える。元の位置には小さな点を残し、転がっている間も「倒れた 〇本」を数え上げる。
  - 最初は止まった後に倒れたピンを薄くするだけだったが、レーンに残ったピンが倒れたのか分からなかったため、倒れた瞬間に形を変えるようにした。

### 多人数で成り立つか

- 各自が自分の1投で勝負する。他人の結果に手を出す方法がないので、押し付けは起きない。
- 手番順による有利不利は小さい（後の人は「何本倒せば最下位を避けられるか」が分かるだけ）。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：真ん中からまっすぐ、強さ50で投げる。

## 画面設計

- 縦長のレーン（上が奥のピン）。両側の溝、奥の落とし穴、スパット（▲の目印）。
- 手番の人の操作：「位置」「方向」「強さ」のスライダー（−／＋で微調整）。レーンをタップすると、その方向に狙いを合わせる。
  狙いの線を点線で、方向のぶれる範囲を黄色の扇で表示する。
- 投げたら全端末で同じアニメーション（サーバー時刻基準）。倒れたピンはその瞬間に横倒しの形になり、「倒れた 〇本」が数え上がる。止まったら「7本！」「ストライク！」「ガター…0本」。
- 一覧は手番順に本数。転がっている間はその人の本数を伏せる。延長戦中は「延長戦 〇回目」。

## 設計

```ts
interface BowlingConfig { wobble: 'low' | 'normal' | 'high' }

interface BowlingState {
  phase: 'aim' | 'rolling' | 'done';
  thrower: PlayerId[];   // 今の回で投げる人（延長戦では最下位で並んだ人だけ）
  turnIndex: number;
  rolloff: number;       // 0: 本戦 / 1〜: 延長戦
  scores: Record<PlayerId, number>;
  history: { rolloff: number; scores: Record<PlayerId, number> }[];
  roll: Roll | null;     // 直前の1投（軌跡・倒れたピン・ピンごとの倒れたコマ・ガターか）
}

type BowlingAction = { type: 'roll'; x: number; angle: number; power: number };
```

- 物理計算はグラスすべらせと共通の `app/games/physics.ts`（摩擦と円の衝突。重さの違いを扱う）。ボールは重さ5、ピンは重さ1。
- レーンは幅60 × 長さ200、1番ピンは手前から140。ボールの初速は `90 + 2.1 × 強さ`。
- 1投の計算はサーバーで1回だけ行い、軌跡を配る。演出用タイマー（軌跡の長さ＋1.5秒）で次の人へ進める。
