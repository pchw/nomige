# ニューニュー（niuniu）

## 概要

**一言ルール：5枚めくって、3枚で10の倍数を作れたら残り2枚の下一桁が点数。一番低い人が負け。**

中国発祥のカードゲーム「牛牛（ニウニウ）」を、飲み会で説明なしに遊べるよう用語を減らして全員参加の形にしたもの。
5枚のカードを「3枚」と「2枚」に分けて考える足し算勝負で、面倒な組み合わせ探しはアプリが自動でやる。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2〜10人（1組のトランプ52枚を5枚ずつ配れる人数） |
| 時間 | 1分 |
| 進行 | 手番制（順番にめくるだけ） |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま押す） |
| 各自スマホ | ○ |
| 隠し情報 | 配られた手札（めくるまで本人も含めて全員に隠れている） |

## ルール

1. 1組のトランプ（ジョーカーなし52枚）を混ぜて、全員に5枚ずつ裏向きで配る。**自分のカードも、めくるまで見えない**。
2. 最初の人はランダム、あとは席順。自分の番に「めくる！」を押すと、5枚が開く。
3. アプリが「合計が10の倍数になる3枚」を探し、残り2枚の合計の下一桁を点数にする。
   - A は 1、2〜10 はそのまま、J・Q・K は 10 と数える。
4. 全員めくったら、**点数が一番低い人の負け**。

### 点数

| 表示 | 条件 | 強さ |
| --- | --- | --- |
| ニューニュー | 3枚で10の倍数を作れて、残り2枚の合計も10の倍数 | 最強（内部値 10） |
| 9 〜 1 | 3枚で10の倍数を作れたとき、残り2枚の合計の下一桁 | 大きいほど強い |
| ウーニュー | どの3枚を選んでも10の倍数が作れない | 最弱（役なし・内部値 0） |

- 例：【3, 7, K, 2, 5】→ 3+7+10 = 20、残り 2+5 = 7 → **7**
- 例：【4, 6, J, 3, 7】→ 4+6+10 = 20、残り 3+7 = 10 → **ニューニュー**
- 3枚の合計は10の倍数なので、点数は「5枚の合計の下一桁」と同じになる。どの3枚を選んでも点数は変わらない（プレイヤーが組み合わせを選ぶ余地はない）。
- 5枚がランダムなときの出やすさ（全組み合わせで計算）：ウーニュー 約34%、1〜9 各約6.5%、ニューニュー 約7%。

### 用語を減らした

元のルールでは「牛七」のように点数ごとに役名があるが、酔っていると分かりにくいので **点数は数字のまま「7」と出す**。
名前で出すのは次の2つだけにした。

- **ウーニュー**：役なし（最弱）。「無牛」で意味が分かりやすく、3回に1回くらい出るので覚えやすい。
- **ニューニュー**：最強。ゲーム名と同じで、出ると派手に表示する（🐮 付きの虹色の札・揺れる）。

### 同点（延長戦）

- 一番低い人が2人以上いたら、**その人たちだけで5枚を配り直して延長戦**（山札は毎回混ぜ直す）。延長戦も最初の人はランダム、あとは席順。
- 延長戦は最大3回。それでも同点ならルーレット。
- ウーニューが約34%と出やすく、一番低い人の同点はよく起きる（6人なら6割以上でウーニューが2人以上）。毎回ルーレットだと味気ないので、「ウーニュー同士でもう1回！」を延長戦として楽しむ。
- 一番高い人の同点は関係ない。

### 元のルールから変えたところ

| 元のルール | このアプリ | 理由 |
| --- | --- | --- |
| 親（ディーラー）と子がそれぞれ1対1で勝負 | 親なし。全員の中で一番低い人が負け | 全ゲーム共通の「1ラウンドで飲む人を1人決める」に合わせる。親を決める手間もなくなる |
| 負けると相手の役の強さに応じて支払いが倍になる（倍返し） | なし | 杯数は1ラウンド1杯で数えている。罰の重さはルームの「罰」設定で決める |
| 同じ点数なら一番強いカード（K > Q > … / マーク順）で比べる | 同点の人だけで配り直し（延長戦） | 追加のルールを覚えなくてよい。延長戦のほうが盛り上がる |
| 自分で3枚を探して並べる | アプリが自動で探す | 酔っていると計算を間違える。組み合わせで点数は変わらないので選ばせる意味もない |

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：手番の人の分をめくる。

## 画面設計

- 「〇〇 がめくる番　残り 〇 人」。延長戦では盤の上に「延長戦 〇 回目（同点だった人だけで配り直し）」、前の勝負で抜けた人を「セーフ 7」のチップで出す。
- 盤は参加者を **めくる順** に縦に並べる。各行に名前・「めくる番」「NEXT」のタグ・点数の札・5枚のカード。
  - めくる前は裏向きのカード（?）。
  - めくると、**10の倍数になる3枚** を色付きの枠でまとめて左に、残り2枚を右に並べ、それぞれの下に足し算（`3+7+10 = 20` / `2+5 = 7`）を出す。ウーニューは5枚をそのまま並べ「どの3枚でも10の倍数にならない」。
  - カードは1枚ずつ時間差でめくれ、全部めくれてから点数の札が出る（約1.3秒）。
- 2人以上めくったら、めくった中で一番低い人の行をピンクにして「今いちばん低い」タグを付ける。
  - めくった直後に切り替えると、カードがめくれる前に「低いかどうか」が分かってしまうので、めくれ終わるまで（1.3秒）は直前の人を除いて判定した表示のままにする。
- 全員めくったら「さあ、どうだ…」→ めくれ終わったら「〇〇 が一番低い！」「同点！〇〇・〇〇 で延長戦」「まだ同点！ルーレットで決める」。
- 手番の人の端末には、画面下に張り付く「めくる！」ボタンを出す（1回押すだけ。選ぶものがないので2段階にしない）。

## 設計

```ts
type NiuniuConfig = {};  // 設定なし

interface Hand {
  cards: PlayingCard[];                     // high-low の PlayingCard を流用
  points: number;                           // 0: ウーニュー / 1〜9 / 10: ニューニュー
  triple: [number, number, number] | null;  // 10の倍数になる3枚のインデックス
}

interface NiuniuState {
  phase: 'flip' | 'shown' | 'done';
  order: PlayerId[];                // 今の勝負の参加者（延長戦では同点の人だけ）
  turnIndex: number;                // 最初の人（手番は order[(turnIndex + flipped.length) % n]）
  hands: Record<PlayerId, Hand>;    // setup / 延長戦の開始時に配る
  flipped: PlayerId[];              // めくった順
  runoff: number;                   // 0: 本戦 / 1〜: 延長戦の回数（最大 3）
  safe: { playerId, points, runoff }[];  // 前の勝負で抜けた人
  lastFlip: { playerId, auto } | null;
}

type NiuniuAction = { type: 'flip' };
```

- `tableView` の `hands` は、めくった人の分だけ返す（まだの人は `null`。手札をクライアントに送らない）。
- 最後の人がめくったら `shown` にしてタイマー `judge`（4秒）を設定する。`judge` で
  - 一番低い人が1人 → 結果（`点数が一番低かった（ウーニュー）` / 延長戦なら `延長戦でも一番低かった（2）`）。
  - 同点で延長戦が残っている → 同点の人だけで配り直して `flip` に戻る。
  - 同点で延長戦を使い切った → ルーレット。
- `tableView.verdict`（`lose` / `runoff` / `roulette`）は `shown` 以降にだけ入れ、画面の結論表示に使う。
- `pendingPlayers`：`flip` 中は手番の人、それ以外は空。
