# グラスすべらせ（glass-slide）

## 概要

**一言ルール：テーブルの端ギリギリを狙ってグラスを滑らせる。端から一番遠い人か、落とした人が負け。**

バーの定番遊び「シャッフルボード」を画面のテーブルで行う。
グラスが滑っていく数秒間をテーブル全員で見守り、「止まれ！」「落ちる！」と騒ぐのが面白さ。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 3〜10人 |
| 時間 | 1〜2分（1人10〜20秒） |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま操作する） |
| 各自スマホ | ○ |
| 隠し情報 | なし（ムラの乱数だけ） |

## ルール

1. 開始プレイヤーはランダム。そこから席順に **1人1回ずつ** 滑らせる。
2. 手番の人は「位置」（左右）と「強さ」を決めて「すべらせる」。止まったグラスはそのまま残る。
3. グラス同士はぶつかって弾かれる。他人のグラスを弾き落としてもよい（自分のグラスも弾かれる）。
4. 全員が滑らせたら決着。
   - テーブルから落ちたグラスがあれば、その人の負け（複数ならルーレット）。弾き落とされた場合も含む。
   - 誰も落ちなければ、奥の端から一番遠い人の負け（同点ならルーレット）。

### 多人数で成り立つか（毒入りチョコの反省）

- 各自が自分のグラスで勝負するので、前の人が次の人を狙って負けに追い込むことはできない。
- 他人を落とすには狙って当てる必要があり、自分のグラスも弾かれて落ちるリスクを負う。
- 後の人ほど状況が見えて有利（カーリングの後攻と同じ）。開始プレイヤーをランダムにして、ラウンドをまたいで均す。

### テーブルのムラ

- 同じ強さでも毎回同じ位置に止まらないよう、初速に乱数で倍率をかける（小さい ±1% / ふつう ±2% / 大きい ±4%）。
- 止まる距離は初速の2乗に比例するので、距離のぶれはその約2倍。画面にはぶれる幅を黄色で表示する。

| 設定 | 選択肢 | デフォルト |
| --- | --- | --- |
| テーブルのムラ | 小さい（腕前勝負）/ ふつう / 大きい（運まかせ） | ふつう |

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：真ん中あたりから、端まで約40cm手前で止まる強さで滑らせる（控えめ）。

## 画面設計

- 縦長のテーブル（上が奥の端、赤線）。端の向こうは「ここに出たら落下」の床。端からの距離の目盛り（25・50・100・150）。
- 手番の人の操作：
  - 「位置」スライダーでスタート位置のグラスが左右に動く。
  - 「強さ」スライダー（0.5刻み）と −／＋ボタン。止まる予定の位置を点線のグラスで、ムラでぶれる幅を黄色の帯で表示する。
  - 「すべらせる 🍺」
- 滑っている間は全端末で同じアニメーション（サーバー時刻基準で再生）。一覧の結果は止まるまで伏せる。
- 一覧は手番順に「あと 〇cm」「落下！」。今の負け候補の行を赤く塗る。

## 設計

```ts
interface GlassSlideConfig { wobble: 'low' | 'normal' | 'high' }

interface GlassSlideState {
  phase: 'aim' | 'sliding' | 'done';
  order: PlayerId[]; startIndex: number; turnIndex: number;
  glasses: { playerId: PlayerId; x: number; y: number; fallen: boolean }[];
  shot: Shot | null;   // 直前の1投。軌跡（30fps の座標列）と開始時刻を持つ
}

type GlassSlideAction = { type: 'slide'; x: number; power: number };
```

- テーブルは幅100 × 長さ200（cm のつもり）、グラスは半径5。
- 物理計算は外部ライブラリを使わず、`applyAction` の中で行う（摩擦で一定の減速、同じ重さの円どうしの衝突）。
  サーバーで1回だけ計算し、軌跡を全端末に配るので、端末によって結果が変わらない。
- 強さ p で進む距離は `2.4p`（ムラなし・衝突なし）。奥の端ちょうどは p ≒ 79。
- 滑らせたら `phase='sliding'` にし、演出用タイマー（軌跡の長さ＋1.2秒）で次の人へ進める。最後の人のタイマーで決着する。
- `pendingPlayers`：`aim` 中の手番の人。
