# 欲張りサイコロ（greedy-dice）

## 概要

**一言ルール：サイコロを好きなだけ振って点を貯める。1が出たら0点。一番低い人が負け。**

「Pig」と呼ばれる定番のサイコロゲームを、1人1手番の飲みゲーにしたもの。
隠し情報がなく、手番の人が振るたびにテーブル全体で「もう1回いけ！」「やめとけ！」と騒ぐのが面白さ。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 3〜10人 |
| 時間 | 1〜2分（1人10秒前後） |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま押す） |
| 各自スマホ | ○ |
| 隠し情報 | なし |

## ルール

1. 開始プレイヤーはランダム。そこから席順に **1人1回ずつ** 手番が回る。
2. 手番の人は「振る」でサイコロを振り、出た目を今回の点に足す。何回でも続けて振れる。
3. 「止める」を押すと今回の点が確定し、次の人の番になる。最低1回は振らないと止められない。
4. **1が出たら今回の点は0点** になり、その場で番が終わる。
5. 全員が終わったら、**一番低い点の人の負け**。同点の最下位が複数いたらルーレット。

### 設定

| 設定 | 選択肢 | デフォルト |
| --- | --- | --- |
| サイコロの数 | 1個 / 2個（どちらかが1ならアウト。1回で約3割がアウト） | 1個 |

### 手番の順番による有利不利

- 後の人ほど「今の最下位」が見えているので、超えるべき点が分かる分だけ有利。
- 開始プレイヤーを毎回ランダムにすることで、ラウンドをまたいで均す。
- 先の人は「高得点を出して後の人にプレッシャーをかける」という楽しみ方ができる。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：1回も振っていなければ1回振る。振っていればそこで止める（2回押せば必ず手番が終わる）。

## 画面設計

- 手番の人の名前、今回の出目（大きなサイコロ）と今回の点を大きく表示。
- 「今の最下位は 〇点」を表示し、超えたら「超えた！止める？」に変わる。
- 「振る 🎲」「止める（〇点で確定）」の2ボタン。
- 手番が変わった直後は、前の人の結果（「〇〇：1が出て 0点！」「〇〇：14点で止めた」）と、アウトになった出目を残す。
- 点数表は手番順。最下位の行を赤く塗る。

## 設計

```ts
interface GreedyDiceConfig { dice: 1 | 2 }

interface GreedyDiceState {
  phase: 'turn' | 'done';
  dice: 1 | 2;
  order: PlayerId[];         // 席順
  startIndex: number;        // 開始プレイヤー（order の添字）
  turnIndex: number;         // 開始プレイヤーから何人目か
  scores: Record<PlayerId, number>;  // 手番を終えた人の確定点
  rolls: Face[][];           // 手番中の人の出目
  turnTotal: number;
  lastTurn: Turn | null;     // 直前の手番の結果（表示用）
}

type GreedyDiceAction = { type: 'roll' } | { type: 'stop' };
```

- 演出用タイマーは使わない。1が出たら即座に次の人の番にし、`lastTurn` で結果を見せる。
- `pendingPlayers`：手番の人。
