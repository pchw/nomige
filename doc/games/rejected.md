# 不採用にしたゲーム案

検討したが採用しなかった案と、その理由。選定基準は [README.md](./README.md#ゲームの選定基準) を参照。
条件が変われば再検討できるよう、理由を残しておく。

## 一度は設計まで行ったもの

| 案 | 内容 | 不採用の理由 |
| --- | --- | --- |
| 数字爆弾 | 1〜100 に隠れた爆弾の数字を順番に避ける | 序盤で爆弾が当たると後ろの人まで手番が回らず白ける。全員同時に選ぶ形にすると、追い詰められていく面白さが薄れる |
| この中で一番〜なのは？ | お題に全員で投票し最多得票者が飲む | 同梱のお題を大量に用意しないと繰り返し遊べない。プレイヤーが出題する形は出題者の腕に依存する |
| ニアピン | 数値クイズで正解から一番遠い人が負け | お題（クイズ）が一度で消費される。出題者モードは出題者の腕に依存する |
| 早押しリアクション | 合図でタップ、一番遅い人が負け | 共有端末では5人以上だと場所が足りず、スマホを置いて囲むのは3人以上で厳しい。各自のスマホで行うと端末性能・回線速度で勝敗が左右される |
| ワードウルフ | 1人だけ違うお題を持つウルフを探す | お題ペアが必要で、一度知ったペアは同じメンバーで使えない |
| 毒入りチョコ（チョンプ） | 板チョコを順番にかじり、左下の毒を食べた人が負け | 多人数だと成り立たない。1人目が毒の上をかじると一番下の1列だけが残り、2人目が毒以外を食べると3人目は毒を食べるしかない。残りが1列になれば、その番の人がいつでも次の人に毒を押し付けられる。一口の大きさを制限すると「30を言ったら負け」と同じになり、アプリである意味がなくなる |

## 提案段階で見送ったもの

| 案 | 内容 | 不採用の理由 |
| --- | --- | --- |
| 美人投票（平均×2/3） | 0〜100 を選び、平均×2/3 に一番遠い人が負け | 検討の結果、見送り |
| 10秒ストップ | 体感で 10.00 秒ぴったりに止める | ストップウォッチアプリで同じことができる |
| 爆弾リレー | 画面上の爆弾を他人に渡し、爆発時に持っていた人が負け | 爆発の瞬間に誰が持っているかが通信速度に左右される。スマホを物理的に回す形だと落下の危険がある |
| 古今東西（山手線ゲーム） | テーマに沿って順番に答える | 本来はリズムに乗って言えなかったらアウトというゲームで、アプリがなくてもできる |
| NGワード | 自分の NG ワードを言ったら負け | 飲み会中ずっと続くタイプで、ラウンドで区切れない |
| インディアンポーカー / コヨーテ | 自分の数字だけ見えない状態で駆け引き | ボードゲーム由来のルールで、酔った状態で理解させるのが難しい |
| 6ニムト！ / ダイヤモンド / 髑髏と薔薇 / ごきぶりポーカー / ノーサンキュー / ワンナイト人狼 | 市販ボードゲーム・カードゲームのルールを借用 | ルール説明が長く、プレイ時間も長め。酔った状態に合わない |
| ジョーカー押し付け | 3ターンの交換後にジョーカーを持っている人が負け | ジョーカーを持っている人だけが交換を選ぶため、すぐに誰が持っているかバレる。全員に交換を強制すると運ゲームになる |
| 罠の宝箱 | 右隣に罠を仕掛け、左隣の箱を開ける | 実質的に 1対1 の勝負が並列で行われるだけで、全体で盛り上がらない |
| マイア（Mäxchen） | サイコロの目を申告して回す | ライアーダイスと役割が重なる。目の強さの順番が特殊で説明しにくい |
| ブラックジャック | 21 に近づけ、超えたらアウト | 101 と「超えたら負け」の性質が重なる |
| サイコロ勝負（チンチロ簡易版） | 3個の合計が一番小さい人が負け | ほぼ運任せで、アプリである意味が薄い |
| 多数派サバイバル / 欲張りタワー | 少数派にポイント / 共有タワーに積む | 被ったらアウト・美人投票と性質が近い |
