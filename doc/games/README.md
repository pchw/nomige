# 飲みゲー一覧

2〜10人程度で遊べる飲みゲーをウェブアプリとして提供する。
各ゲームは「ゲームを1回（1ラウンド）行う → 負け（飲む人）を1人決める」という形に統一する。

## ゲームの選定基準

検討の結果、以下をすべて満たすものを採用した（不採用案とその理由は [rejected.md](./rejected.md)）。

1. **ルールが一言で伝わる**：酔った状態でも説明なしで遊べる。
2. **1ラウンドが短い**：1〜3分程度。
3. **全員が参加し続けられる**：手番が回ってこない・長時間待つだけ、という状態を作らない。
4. **アプリである意味がある**：隠し情報、同時に秘密で入力、カードやサイコロの代わり、面倒な処理の自動化のいずれかがある。何もなくてもできる・既存アプリでできるものは対象外。
5. **お題データや出題者の腕に依存しない**：何度遊んでもネタ切れしない。
6. **通信速度や端末性能で勝敗が決まらない**：反射神経・早押し系は扱わない。
7. **スマホの受け渡しをしない**：落下の危険がある。共有端末（テーブルに置いたタブレット）はその場で操作する。
8. **時間で急かさない**：酔っていると選択に時間がかかる。制限時間で打ち切らず、全員が選ぶまで待つ。止まったときは「おまかせで進める」で進める（[common-design.md](./common-design.md#おまかせで進める)）。

### タブレット1台で遊ぶゲーム

101・ライアーダイス・狼と子豚は、手札や役職が見えると成り立たないため、共有端末では目隠し画面（ホットシート）で交代しながら操作する。被ったらアウト・ハイローは手元に見る情報がないので目隠しを挟まず、「〇〇さんの番」と出た人が順番に選ぶ。
テーブルにタブレットを置いたまま全員で見て遊べるよう、**隠し情報のない手番制のゲーム** として欲張りサイコロ・地雷原・グラスすべらせ・ボウリング・ビアポン・ロシアンルーレット・あみだくじを加えた。

- 全員に隠れた乱数（サイコロの目・地雷の位置・テーブルのムラ・投げのぶれ・ハズレのグラス・隠れた横線）と、公開された盤だけで進む。
- グラスすべらせ・ボウリング・ビアポンは「狙って投げる」系。操作はスライダーで決めてボタンを押すだけ（反射神経・制限時間なし）。止まる位置やぶれる範囲を画面に出して「どれくらい飛ぶか分からない」をなくし、結果は距離・本数・入ったかどうかで数字ではっきり決める。
- 各手番のリスクを手番の人自身が負う。前の人が次の人を狙って負けに追い込めるゲーム（毒入りチョコ）は多人数で成り立たないため不採用にした（[rejected.md](./rejected.md)）。
- 手番の人の操作を全員で見守り、口を出すのが楽しさになる。
- `GameDefinition.publicBoard = true` のゲームは、共有端末でも目隠し画面を出さず、手番の人がそのまま操作する（[common-design.md](./common-design.md#共有端末での隠し情報ホットシート)）。ゲームカードには「タブレット1台◎」を表示する。
- 各自スマホでも遊べるが、自分の番以外は見ているだけなので「○」。

### 世界観

「被ったらアウト」「狼と子豚」は動物キャラクターを使う。キャラクターの絵柄・色を全ゲームで共通化し、プレイヤーのアイコンにも使う（[common-design.md](./common-design.md#9-キャラクターアセット)）。

## 全ゲーム共通のルール

- 1ラウンドの結果として **敗者（飲む人）を1人** 決める。
  - ゲームのルールで1人に決まらない場合（同点・同時など）は、共通の「**ルーレット**」演出で1人を抽選する。
  - 「負けた人たちで次のラウンド」のように、候補者だけで延長戦を行うゲームもある。延長戦中、抜けた人は観戦になるが、延長戦は1回数十秒で終わる。
- ラウンド終了後、同じメンバー・同じ設定で「もう1回」ができる。ルーム内で各プレイヤーの **累計杯数** を記録し表示する。
- 飲酒に関する配慮
  - ルーム作成時に「20歳未満の飲酒は法律で禁止されています」「ソフトドリンクでも遊べます」を表示する。
  - 罰を「1口」「1杯」「ソフトドリンク」など自由テキストで設定できる（表示用のみ）。
  - 各プレイヤーは1ルームにつき設定回数（デフォルト1回）の **パス権** を使える。
  - 累計杯数が一定数（デフォルト5）を超えたプレイヤーには「水を飲もう」表示を出す。
