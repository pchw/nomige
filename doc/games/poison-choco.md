# 毒入りチョコ（poison-choco）

## 概要

**一言ルール：板チョコを順番にかじる。左下の毒を食べた人が負け。**

組合せゲームの「チョンプ（Chomp）」を多人数の飲みゲーにしたもの。すべて公開された盤で進む。
大きく食べて追い込むか、少しずつ刻むか。終盤は「毒が何人目に回るか」を数える駆け引きになる。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 3〜10人 |
| 時間 | 1分前後 |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま押す） |
| 各自スマホ | ○ |
| 隠し情報 | なし |

## ルール

1. 開始プレイヤーはランダム、あとは席順。
2. 手番の人は、残っているチョコを1かけ選ぶ。
3. 選んだかけらと、その **右と上にあるチョコを全部まとめて** 食べる。
4. 左下の1かけ（☠️）だけが毒。毒を食べた人の負け。

- 毒は、ほかのチョコが全部なくなるまで選べない（自分から負けにいく操作をなくす）。
- 毒しか残っていなければ、手番の人は毒を食べるしかない。

### 設定

| 設定 | 選択肢 | デフォルト |
| --- | --- | --- |
| チョコの大きさ | 小（5×4）/ 中（6×5）/ 大（7×6） | 中 |

### アプリである意味

- 紙でも遊べるゲームだが、「右上をまとめて消す」処理と、食べる範囲のプレビューを自動化することで、酔っていても間違えずに遊べる。
- 2人なら先手必勝と知られているが、3人以上では誰に毒を回すかの読み合いになり、酔った状態で解き切ることはない。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：一番右の列のてっぺんを1かけだけ食べる（毒しかなければ毒）。

## 画面設計

- 席順のチップ（手番・NEXT）、「〇〇 の番」「直前：〇〇 が 6個 食べた」。
- 盤の上に「残り 〇 かけ」。毒だけになったら「毒しか残っていない！」。
- かじる場所をタップすると、食べる範囲が黄色く点滅し「ここから 〇個 食べる」ボタン（同じ場所をもう一度タップしても食べる）。
- 食べた跡は点線の枠で残し、盤の形が分かるようにする。

## 設計

```ts
interface PoisonChocoConfig { size: 'small' | 'normal' | 'large' }

interface PoisonChocoState {
  phase: 'turn' | 'poisoned';
  cols: number; rows: number;
  heights: number[];   // 列ごとの残りの高さ（左から、右へ増えない）。row 0 が一番下、(0, 0) が毒
  order: PlayerId[];
  turnIndex: number;
  lastBite: Bite | null;
  log: Bite[];
}

type PoisonChocoAction = { type: 'eat'; col: number; row: number };
```

- (col, row) を食べると、`col` 以降の列の高さを `row` 以下にする。
- `pendingPlayers`：手番の人。
