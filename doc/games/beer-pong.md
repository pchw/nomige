# ビアポン（beer-pong）

## 概要

**一言ルール：カップにボールを入れた人から抜ける。最後まで入れられなかった1人が負け。**

奥に三角形に並んだ10個のカップを狙ってボールを投げる。入ったら抜けてセーフ、入ったカップは片付ける。
ハイローと同じ勝ち抜け形式にすることで、「外れた人がみんな0点で並ぶ」問題をなくしている。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 3〜10人 |
| 時間 | 1〜3分（10人で平均25投ほど） |
| 進行 | 手番制（勝ち抜け） |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま操作する） |
| 各自スマホ | ○ |
| 隠し情報 | なし（投げのぶれの乱数だけ） |

## ルール

1. 開始プレイヤーはランダム。そこから席順に1投ずつ回す。
2. 「方向」と「強さ」を決めて「投げる」。
3. カップに入ったら、その人は抜ける（セーフ）。入ったカップは片付ける。
4. 入らなかった人は、また順番が来たら投げる。
5. 残りが1人になったら、その人の負け。

- カップの中心から 3.2 以内に落ちたら入る。縁（6.5 以内）に当たったら弾かれて外れ。
- 80投しても決まらなければ、残っている人からルーレット（通常は起きない）。

### 投げのぶれ

落ちる場所は、方向と強さで決まる予定の場所から、距離と方向にぶれる。遠くに投げるほどぶれる範囲が大きくなるので、手前のカップほど入れやすい。

| 設定 | 距離のぶれ | 方向のぶれ | 入る確率（真ん中を狙ったとき） |
| --- | --- | --- | --- |
| 小さい（入りやすい） | ±2% | ±0.75° | 約70% |
| ふつう | ±3% | ±1.1° | 約40% |
| 大きい（入りにくい） | ±4.5% | ±1.7° | 約20〜45% |

- 確率はカップがすべて残っているときの目安。まわりのカップにこぼれて入ることもある（真ん中のカップほど入りやすい）。
- 平均の投げる回数（ふつう）：3人で約5投、6人で約14投、10人で約25投。

### 多人数で成り立つか

- 自分が抜けるために投げるだけで、他人を負けに追い込む手はない。
- カップを減らすと後の人が不利になるが、それは入れた本人が抜けるための結果。
- 最初の人は、カップが多い分だけ少し有利。開始プレイヤーをランダムにして均す。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：残っているカップを1つ選んで、その真ん中を狙って投げる。

## 画面設計

- 上から見たテーブルの奥側（カップのまわり）だけを表示する。ボールは手前から飛び込んでくる。
- 手番の人の操作：「方向」「強さ」のスライダー（−／＋で微調整）。狙いたいカップをタップすると、そこに向けて方向と強さを合わせる。
  落ちる予定の場所に十字、ぶれる範囲を黄色の楕円で表示する。
- 投げたら全端末で同じアニメーション（1.4秒の放物線、影とボールの大きさで高さを表す）。「IN！🍺」「縁で弾かれた！」「外れ…」。
- 片付けたカップは点線の丸に、入れた人のキャラを表示する。
- 一覧は「まだ入れていない人」と、抜けた順（1抜け、2抜け…）。

## 設計

```ts
interface BeerPongConfig { wobble: 'low' | 'normal' | 'high' }

interface BeerPongState {
  phase: 'aim' | 'flying' | 'done';
  remaining: PlayerId[];   // まだ入れていない人（投げる順）
  turnIndex: number;
  exited: { playerId: PlayerId; cupId: number }[];
  cups: { id: number; x: number; y: number; takenBy: PlayerId | null }[];
  throws: number;
  shot: Throw | null;      // 直前の1投（落ちた場所・結果・弾かれた先）
}

type BeerPongAction = { type: 'throw'; angle: number; power: number };
```

- 物理計算は使わない。落ちる場所を計算して、カップとの距離で判定するだけ。
- テーブルは幅80 × 長さ240。投げる位置は手前の真ん中、1番手前のカップは 190。飛ぶ距離は `120 + 1.2 × 強さ`。
- 演出用タイマー（飛ぶ1.4秒＋弾む0.4秒＋結果1.3秒）で次の人へ進める。
