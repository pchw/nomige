# ロシアンルーレット（russian-roulette）

## 概要

**一言ルール：順番にグラスを選ぶ。ハズレを引いた人が負け。**

人数分のグラスのうち1つだけがハズレ。全員が選び終えてから一斉に開示する。
誰が何番を選んだかは全員に見えるので、選ぶ瞬間と開示の瞬間をみんなで盛り上がれる。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2〜10人 |
| 時間 | 1分 |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま押す） |
| 各自スマホ | ○ |
| 隠し情報 | ハズレの位置（全員に隠れている） |

## ルール

1. グラスは参加人数と同じ数。そのうち1つがハズレ。
2. 開始プレイヤーはランダム、あとは席順。手番の人はまだ選ばれていないグラスを1つ選ぶ。
3. 最後の人には残った1つを自動で配る（選ぶ余地がないため）。
4. 全員が選び終えたら、溜め（2.5秒）のあとハズレを開示。引いた人の負け。開示したグラスを2.5秒見せてから結果画面に移る。

- グラスが人数分なので、必ず1ラウンドで1人に決まる。
- ハズレを引く確率は何番目に選んでも 1/人数 で、順番による有利不利はない。
- 運だけのゲームだが、「アプリである意味」は全員に隠れたハズレの位置を持つことにある（紙やコップでやると準備する人が位置を知ってしまう）。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：空いているグラスからランダムに選ぶ。

## 画面設計

- 席順のチップ（手番・NEXT）、「〇〇 の番」「直前：〇〇 が 2 番を選んだ」。
- グラスを番号付きで並べ、選ばれたグラスには選んだ人のアイコンを出す。
- グラスをタップするとすぐに決まる（テンポ優先で確認ボタンは出さない）。
- 開示前の溜めでは全グラスが揺れ、開示でハズレのグラスが 💀 になって赤く光る。

## 設計

```ts
type RussianRouletteConfig = Record<string, never>; // 設定なし

interface RussianRouletteState {
  phase: 'pick' | 'reveal' | 'shown' | 'done';
  poison: number;                // ハズレのグラス（setup で決める）
  pickedBy: (PlayerId | null)[]; // グラスごとに選んだ人
  order: PlayerId[];
  turnIndex: number;             // 最初の人
  picks: number;                 // 選んだ人数（手番は order[(turnIndex + picks) % n]）
  lastPick: Pick | null;
}

type RussianRouletteAction = { type: 'pick'; glass: number };
```

- `tableView` の `poison` は `shown` になってから返す（それまではクライアントにハズレの位置を送らない）。
- 全員が選んだら `reveal` にしてタイマー `reveal` を設定。`reveal` で `shown` にしてハズレを見せ、タイマー `finish` で結果を返す。
  - 結果を返すとルームがすぐ結果画面に移るため、開示と結果を分けている。
- `pendingPlayers`：`pick` 中は手番の人、それ以外は空。
