# 地雷原（minesweeper）

## 概要

**一言ルール：順番にマスを1つ開ける。地雷を踏んだ人が負け。**

マインスイーパーを全員で1つの盤を囲んで遊ぶ形にしたもの。開けたマスには周りの地雷の数が出るので、運だけでなく推理がある。
全員で盤を見ながら「そこは危ない！」と口を出せるので、手番でない人も参加し続けられる。
**タブレット1台をテーブルに置いたまま遊ぶ** ことを想定したゲーム。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2〜10人 |
| 時間 | 1〜2分 |
| 進行 | 手番制 |
| 共有端末 | ◎（目隠しなし。手番の人がそのまま押す） |
| 各自スマホ | ○ |
| 隠し情報 | 地雷の位置（全員に隠れている） |

## ルール

1. 開始プレイヤーはランダム、あとは席順。
2. 手番の人は、まだ開いていないマスを1つ開ける。
3. 安全なマスなら、周り8マスにある地雷の数が出て次の人の番。
4. 地雷を開けた人の負け。

- **1マス目は必ず安全**（地雷は最初のマスが開いてから、そのマス以外に配置する）。
- 0 のマスを開けても周りを自動では開けない（1手 = 1マス）。0 の周りは安全と分かるので、後の人への「ボーナス」になる。
- 安全なマスが残っていなければ、次の人はどこを開けても地雷。必ず決着する。

### 盤の大きさと地雷の数

| 人数 | 盤 | 少なめ | ふつう | 多め |
| --- | --- | --- | --- | --- |
| 2〜5人 | 6×6 | 5個 | 8個 | 11個 |
| 6〜10人 | 6×8 | 7個 | 11個 | 14個 |

- 「数字爆弾」を不採用にした理由（序盤に当たると後ろの人に手番が回らない）への対策として、人数が多いときは盤を広げる。
- 地雷の割合（15% / 22% / 30%）は、推理だけでは開け続けられず、1〜2周のうちに運試しが必要になる程度にしている。

### 待ち時間とおまかせ

- 制限時間なし。
- おまかせ：0 の隣など確実に安全なマスがあればそこを、なければランダムに開ける。

## 画面設計

- 席順のチップ（手番・NEXT）、「〇〇 の番」「直前：〇〇 が 2 を開けた」。
- 盤の上に「💣 〇個 / 安全なマス 残り 〇」。0 になったら「もう安全なマスはない！」。
- マスをタップすると黄色く選択され、「このマスを開ける」ボタン（同じマスをもう一度タップしても開ける）。テーブルに置いた端末を誰かが触ってしまっても、1タップでは開かない。
- 直前に開いたマスはオレンジの枠。爆発したら全地雷を公開し、踏んだマスは 💥。

## 設計

```ts
interface MinesweeperConfig { mines: 'few' | 'normal' | 'many' }

interface MinesweeperState {
  phase: 'turn' | 'boom';
  cols: number; rows: number; mineCount: number;
  mines: number[] | null;          // 最初の1マスが開くまでは null
  opened: (number | null)[];       // 開いたマスの数字
  openedBy: (PlayerId | null)[];
  order: PlayerId[];
  turnIndex: number;
  lastOpen: Open | null;
  boomCell: number | null;
}

type MinesweeperAction = { type: 'open'; cell: number };
```

- `tableView` の `mines` は爆発後だけ返す（それまではクライアントに地雷の位置を送らない）。
- `pendingPlayers`：手番の人。
